# Security Policy

## Supported Versions
Only the latest version of ProjectPilot.AI (v1.0.0+) is currently supported with security updates.

## Reporting a Vulnerability
We take the security of our application seriously. If you identify a security vulnerability (such as API keys leakage, token issues, or command injection vulnerabilities), please do not open a public issue.

Instead, report the vulnerability by reaching out to the author directly:
- Contact: **Snehith** via Github [Snehith1302](https://github.com/Snehith1302)

Please provide a detailed description of the vulnerability, execution pathways, and reproduction code steps. We will review your report and coordinate remediation steps as soon as possible.
